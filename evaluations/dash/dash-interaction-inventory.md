## Cross-cutting semantics

- **Single informant.** The Register captures one `Informant ID` (p1). There is **no** Parent/Child/Summary column structure. A case may be keyed by `Family ID` / `Individual ID` / `Informant ID` and a calculated `Study ID`, but each administration is one informant's account.
- **Response anchors.** The dominant item is `No / Yes / Unk` (sometimes `N/A`, `Current`). Frequencies use `Never / Rarely / Sometimes / Often / Always / Unk`. Distress and impairment use a `0–10` scale with `N/A` / `Unknown`. Substance-frequency grids use `No / Once / Twice / Three or more times`.
- **Clinician ratings are first-class data.** Every disorder closes with `Diagnostic Rating` (`No disorder` / `Symptoms of disorder, but no impairment` / `Symptoms of disorder, plus impairment` / `Meets diagnostic criteria for disorder` / `N/A` / `Unknown`), `Severity Rating` (`Mild` / `Moderate` / `Severe` / `N/A` / `Unknown`), and `Certainty of Diagnostic Rating` (`Good` / `Fair` / `Poor` / `N/A` / `Unknown`). These are repeated per diagnosis (30 `Diagnostic Rating` blocks in the extraction, each paired with a severity and certainty block).
- **Module selection is interviewer-driven and score-guided, not hard-coded.** The 25 calculated scores are hints; the interviewer completes the Screener Checklist and administers the modules they judge applicable.
- **No fixed administration order.** Modules are independent; skip/end instructions route within each.
- **Episode coding is explicit.** Major Depression and Mania/Hypomania contain a printed **worst-episode decision table** (Groups A–D) mapping *current* × *worse/more-severe* answers to which episode is coded (lines 3539–3572).
- **Risk handling is an instruction, not a flow.** The suicide screener says: *"If current or participant feels this way now, report to clinician/assess current risk level immediately."* (line 1440). The instrument does not branch to an escalation flow; it tells the interviewer to act.
- **Reusable sub-modules.** Help-Seeking Treatment appears 25×, Distress/Impairment 56×, and an Associated Conditions block (Medical / Alcohol-Drugs-Tobacco) recurs across modules.

## Notes for the compliance evaluation

- **DASH is materially simpler than KSADS on the hardest axis.** It is single-informant: there are no Parent/Child/Summary columns and no cross-informant synthesis, so the KSADS multi-informant gap does not arise. A multi-session `case` model is optional, not required.
- **The recurring strain points are computational and iterative, not conversational.** P04/P18 need numeric aggregation over item sets; P12 needs a 2-D grid; P09/P10/P11 need collection-driven repetition.
- **Routing is deterministic and enumerable.** P06/P08/P20 are ordinary conditional routing; P08 is a printed 4-way lookup, which is a `branch`, not a `decide` (it is multi-way).
- **Clinician ratings are ordinary structured capture.** P07/P24 are `ask` forms; the only wrinkle is that the respondent is the clinician, which the session `role` covers.
- **P21 is advisory.** DASH does not prescribe an escalation graph; encoding one is an authorial choice.
